## 1 要回答的唯一问题

> 在真实在线观测限制下，**主动安排健康检查时刻**能否在**相同检查成本**下取得比
> **最强固定检查策略**更低的总决策损失？

必须分别识别三件事，不得混为一个实验：

| 编号 | 量 | 定义 | 本轮的处置 |
|---|---|---|---|
| **Q1** | 健康信息的**预测价值** | 有健康观测 vs 无健康观测（仅年龄+应力）在同一决策时点的损失差 | **不重做**——阶段 D 已建立（ISU −19.6% [−27.3,−11.0]）。本轮只把它作为分母/参照 |
| **Q2** | 健康信息的**时间价值** | 固定 N，改变**哪些**时点被观测，损失的变化 | **本轮测量对象**（含 oracle 上界） |
| **Q3** | **主动选择时刻**的决策价值 | 在线策略（只用已观测信息）选时点 vs 最强固定策略，同 N 同成本 | **本轮主检验**，且必须先证明 Q2 有头部空间 |

**Q3 的有效上界**：任何在线策略 ≤ 事后最优子集（oracle）。因此
`Q3 ≤ oracle − strongest_fixed`。若该上界小于门槛，Q3 不可能达标——**这是证明，不是实验失败**。

## 3 决策问题（单位固定）

**决策时点 T**（预注册网格）：`T ∈ {56, 63}` 天。两档都报，不得只报有利的一档。

**动作**：对每颗电芯，在 T 时刻承诺一个**计划更换/复检时刻** `R ≥ T`。

**观测**：
- `t_0` = 首个 RPT（第 0 天），**强制且免费**（出厂/入库标定），所有策略相同 →
  这就是"统一初始信息"。
- 策略从候选集 `C(cell) = {RPT 时刻 ∈ (t_0, T]}` 中选 **N** 个额外时点。
- **N ∈ {1, 2, 3}**（预注册网格），即总点数 2/3/4。N=1 与阶段 D 的 k=2 对接。
- **成本** `c_insp × N`（只计额外检查；`t_0` 不计费）。

**特征**（只由被选中的观测计算，**不读任何未选中的 RPT**）：
`logT`、`DoD`、`charge_C`、`discharge_C`、
`soh_first`、`soh_last`、`frac_loss`、`ols_slope`、`ols_se_slope`、`ols_r2`、
`ols_resid_sd`、`ols_soh_at_T`、`ols_curv`、`span`、`n_obs`。
（沿用 `D_common.usable_features()`：单一取值的列显式丢弃并报告。）

**模型**：`HistGradientBoostingRegressor(max_iter=300, lr=0.05, random_state=0)`，
外层**留一工况**；每个训练折在**该折所有工况的全部允许子集**上训练（子集增广），
使模型能处理任意子集——这是给 oracle 上界留足余地所必需的。

**目标**：`y = log M`，`M = (L+U)/2` 为 EOL 区间中点。
敏感性另报 `y = log L` 与 `y = log U`。

**决策规则**：`R = exp(prediction)`，其中 prediction 是**损失最优分位**，不是条件均值。

不对称线性损失下（`c_w` 对提前、`c_f` 对超期）的最优动作是预测分布的
`τ = c_w / (c_w + c_f)` 分位：

| `c_f/c_w` | 2 | 5 | 10 |
|---|---|---|---|
| `τ` | 1/3 ≈ 0.333 | 1/6 ≈ 0.167 | 1/11 ≈ 0.091 |

因此模型用 `HistGradientBoostingRegressor(loss="quantile", quantile=τ)`。
**若用 L2 拟合再取点预测，动作对该损失不是最优的，各策略比较会失真**
（Codex 在阶段 D 已指出这一点）。所有策略共用同一 τ 与同一模型族，故比较公平。

**决策损失**（单位：天，`c_w = 1`）：

```
Loss = max(0, M − R) + (c_f/c_w) · max(0, R − M)
```

- `R < M`：提前更换 → 浪费剩余寿命 `M − R` 天（权重 1）
- `R > M`：超期使用 → 失效暴露 `R − M` 天（权重 `c_f/c_w > 1`）

**总目标**：`J = c_insp · N + E[Loss]`，单位 = 天。`c_err` 归一为 1。

**预注册成本网格**（全部报告，不得事后挑选）：

| 参数 | 取值 | 含义 |
|---|---|---|
| `c_insp` | {0.5, 1, 2} 天/次 | 一次检查相当于浪费多少天寿命 |
| `c_f/c_w` | {2, 5, 10} | 超期使用相对提前更换的日损失倍数 |

共 9 个成本单元 × 2 个 T × 3 个 N。**全部报告**。

## 4 策略集（至少 5 条）

| 策略 | 定义 | 是否用健康信息选时点 |
|---|---|---|
| `FixedEven` | 在 `C` 上取最接近等间隔的 N 个时点（固定日历日程） | 否 |
| `FixedLate` | 取 `C` 中**最后** N 个时点（决策前集中检查） | 否 |
| `Random` | 从 `C` 均匀随机取 N 个；20 个预注册种子取平均 | 否 |
| `Uncertainty` | 每步选使预测不确定度下降最大的时点（HGB 残差分位宽度代理） | 是 |
| `VoI` | 标准信息价值：每步估计"再买一次"带来的期望损失下降，超过 `c_insp` 才买 | 是 |
| `Candidate` | **见 §5** | 是 |

**"最强固定策略"** = `max(FixedEven, FixedLate, Random)` 在该成本单元下的 J 最优者。
门槛对照的是它，不是随便挑一条。

## 5 Candidate 的机制（必须与 VoI 可分辨）

**机制名**：**双向时间杠杆（two-sided temporal leverage）**。

**主张**：一次检查的信息只有同时满足两个条件才有决策价值——
(a) **信息量足够**：已观测到可测的退化幅度（太早 = 噪声）；
(b) **剩余可行动时间足够**：距 T 还有提前量，信息能改变 R（太晚 = 无用）。
故信息价值在时间上呈**倒 U**：两端都低。

**与标准 VoI 的可分辨差异**（这是进正式训练的前提）：
标准 VoI 是**单边**的——不确定度随观测增多单调下降，故 VoI 倾向于"越晚越好、越买越好"，
没有"太早没用"的结构。Candidate 预测**内部最优时点**，且预测
**Candidate 的优势集中在"信息窗与可行动窗重叠很窄"的单元**（即 T 相对于典型寿命偏晚、
或退化噪声大的工况）。

**可证伪预测**（预注册）：
1. Candidate 选出的时点分布应有内部众数，而非集中在 `C` 的末端；
2. Candidate 的 J 优势应在"重叠窄"的单元更大，而在"重叠宽"的单元与 VoI 无差异。

若 Candidate 与 VoI 的选点分布无差异（Jaccard > 0.8）或上述 2 不成立，
**Candidate 记为被否决**，不得改写成"与时序无关"或重新命名。

## 6 可识别性门槛（E1，正式训练之前）

七条必须逐条通过，任一失败即 **NO-GO**，不进入 §7 的正式回放：

| # | 门槛 | 判定方法 | 通过标准 |
|---|---|---|---|
| I1 | 不同策略产生**不同**可观测历史 | 各策略选出的子集两两 Jaccard | 所有策略对的中位 Jaccard **< 0.95** |
| I2 | 改变检查时刻**实际改变**预测/决策 | 固定电芯，跨子集的 `R` 与 `Loss` 的离散度 | `Loss` 的跨子集变异系数 **> 0.02** |
| I3 | 决策损失**不是常数** | `J` 在成本单元×策略上的取值范围 | 极差 / 中位 **> 0.05** |
| I4 | 策略**不用**未来容量/EOL/完整轨迹 | 代码审计 + 运行时断言：任何特征只能由 `C` 中被选时点计算 | 0 违规 |
| I5 | 数据支持离线时序回放 | 候选时点数、时间戳完整性 | E0 已确认：T=63 时 m=7–9 |
| I6 | 现有检查日程**足以**识别策略效果 | **oracle 上界**（见 §6.1） | `(J_fixed − J_oracle)/J_fixed ≥ 10%` 至少在一个成本单元成立 |
| I7 | 被跳过的检查**可以合法隐藏** | 断言：回放时未选时点的容量值不可被任何代码路径读取 | 0 违规 |

### 6.1 I6 的 oracle 上界（本轮最关键的判据）

对每颗电芯、每个 (T, N)，**枚举 `C` 的全部 N-子集**，用同一个模型算出每个子集的 `R`
与 `Loss`，取**事后最小**者作为该电芯的 oracle。按工况聚合成 `J_oracle`。

- oracle **允许使用完整轨迹来挑选**（事后），因此它**高估**任何在线策略可达的收益 →
  `Q3 ≤ J_fixed − J_oracle` 是**有效上界**。
- 若该上界 < 10%（相对最强固定策略），**Q3 不可能达标** → 立即 NO-GO，
  不消耗 12 小时预算。

**这是本轮的主要产出之一**：无论 GO 还是 NO-GO，它都给出"主动选时点最多值多少"的定量答案。

## 7 正式回放（仅当 §6 全通过）

- 外层留一工况；时间顺序回放；预测时只用已观测信息；
- 统一初始信息（`t_0` 免费且相同）、统一决策时点 T、统一检查成本、相同可评价总体；
- **成本与损失分别报告**（`c_insp·N` 与 `E[Loss]` 两个分量都要给）；
- 配对工况级 95% CI；全部 9 个成本单元 × 2 个 T × 3 个 N 报告；
- 保存**逐工况、逐电芯**的检查记录、预测、`R`、`Loss`。

**主门槛（预注册）**：
> `Candidate` 相对"最强固定策略"的 `J` 相对下降 **≥ 10%**，
> 且配对工况级 95% CI 的**上界 < 0**。

`Candidate` 还必须**同时**击败 `VoI`（同门槛），否则优势归于"更多观测/更多计算"
而非新机制，按 §6 判为不成立。

## 10 已知局限（冻结时声明，不得事后补充为"发现"）

1. **离线回放的动作空间是"实际存在的 RPT 时点"**，不是任意时刻。因此本轮的"选时点"
   = 在既有检查日历上**选用/跳过**，而非在连续时间上排程。这是真实车队运维的常见形态，
   但**不能**外推为"任意时刻可检查"的结论。
2. **EOL 是参考日程下的检出时刻**：`U` 依赖于检查密度。所有策略共用同一目标，
   故对比公平；但**不得**把"少检查 → 检出更晚"算作收益。
3. **入样条件 `L > T` 是幸存者总体**：在 T 时刻仍存活的电芯寿命偏长。结论只适用于该总体。
4. **区间删失**：`M=(L+U)/2` 是声明过的近似；中位区间宽度/寿命 = 8.8%（p95 = 24%），
   敏感性用 `L`、`U` 端点另报。
5. **Q1 的价值（−19.6%）来自阶段 D 的预测指标**，不是决策损失；两者不得互相替代。
