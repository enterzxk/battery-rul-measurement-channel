# RESULT C · 检查预算（第 3 部分）：共同 landmark 设计，两队列**不一致**

> 程序 `online-mechanisms-20261110` · T+01:00
> 修正了两次总体漂移后得到的结果

---

## 1 为什么需要第三次

前两次 C 分析**不可比**：

- UConn 用「整条日程抽稀 k 倍」；
- ISU 用「前 N 次检查」（landmark 设计）。

而且 **ISU 的第一次曲线又犯了总体漂移**：N 越大，只有 RPT 多的电芯存活，而它们寿命系统性不同。修正后（固定 186 个 ≥12 次 RPT 的电芯）才有效。

本部分把两个队列放到**同一个 landmark 设计**：每个电芯只用其**前 N 次检查**预测 EOL，留一工况，condition-macro。

## 2 结果（固定总体）

| N | UConn（64 电芯 / 11 工况） | ISU（186 电芯 / 50 工况） |
|---:|---:|---:|
| 2 | 0.3225 | 0.2630 |
| 3 | 0.2478 | 0.2635 |
| 4 | 0.2431 | 0.2650 |
| 6 | **0.2422** | 0.2240 |
| 8 | 0.2494 | 0.1575 |
| 12 | 0.2912 | **0.1150** |
| **N=2→12** | **−9.7%** | **−56.3%** |

## 3 判读

1. **ISU 单调改善**：从 N=2 的 0.263 降到 N=12 的 0.115，**−56%**。早期观测越多越准。
2. **UConn 不改善**：N=3 就到 0.248，N=6 最低 0.242，**N=12 反而升到 0.291**。净变化 −9.7%，且非单调。
3. **两个队列方向不一致，不能合并成一条结论。**

## 4 为什么会不一致（一个未被排除的混淆）

**同样的 N，在 ISU 上是晚得多的 landmark。**

| 队列 | 检查间隔 | 典型寿命 | 一次检查占寿命 |
|---|---:|---:|---:|
| UConn | ~98 循环 | 3500–8000 循环 | **~1.5–2.8%** |
| ISU | ~8 天 | ~141 天 | **~5.7%** |

所以 **N=12 在 UConn 上只看到寿命的 15–30%，在 ISU 上看到约 68%**。同样的 N 不是同样的信息量。

**这是本结果最大的限制**：N 与「已观察寿命比例」耦合。要真正比较，landmark 必须固定在**寿命分数**上，而不是固定检查次数。而固定分数后，可用的检查次数又由各自的日程决定——这正是 A 撞到的同一堵墙。

## 5 与前面结果的关系

| 分析 | 结论 | 状态 |
|---|---|---|
| A（暴露 vs 每检一步） | 电芯内节奏规则，两种参数化等价 | DATA-NOT-IDENTIFIABLE |
| C-1（UConn 抽稀） | 4× 抽稀涨 20.1%（p=0.024），排序不退化 | POSITIVE（但仅 11 工况） |
| C-2（ISU 固定 N vs 应力） | 误差不随应力变化 | NOT-SUPPORTED |
| **C-3（共同 landmark）** | **两队列方向相反** | **INCONSISTENT** |

**C-1 与 C-3 的 UConn 部分是一致的**（UConn 上减少检查代价不大）。**C-2 与 C-3 的 ISU 部分矛盾**：C-2 说 N=3..8 误差持平（0.062–0.069），C-3 说 ISU 从 0.26 降到 0.12。

**矛盾原因**：C-2 的 `cond-macro` 用的是**不同总体**（204 电芯 / 52 工况，每个 N 单独筛），C-3 用固定 186 电芯 / 50 工况。**C-2 作废。**

## 6 判定

| 主张 | 判定 |
|---|---|
| UConn 上检查预算可以大幅削减而代价有限 | **WEAKLY-SUPPORTED**（20% 代价 @ 4×，仅 11 工况） |
| ISU 上早期观测越多越准 | **POSITIVE**（−56%，固定总体，50 工况） |
| 所需检查预算不依赖应力 | **WITHDRAWN**（C-2 总体漂移，作废） |
| 两个队列可合并成一条检查预算结论 | **NOT-ESTABLISHED**（方向相反 + landmark 混淆） |

## 7 限制

1. **landmark 混淆未解决**：固定 N ≠ 固定寿命分数。这是本部分的核心缺陷。
2. UConn 只有 11 个工况。
3. UConn 的循环轴有已知缺陷（CORRECTIONS C1/C2，未冻结的 gap 规则）。
4. 单模型（HGB）、单轴定义。
5. 未做独立代码审计。
