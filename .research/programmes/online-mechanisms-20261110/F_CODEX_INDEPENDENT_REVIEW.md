## 第二轮：修复后复审 — **CLOSE**

### 被接受的修复

| 修复 | Codex 判定 |
|---|---|
| DoD 感知准入（208/208） | **接受**；"withdraw the previous objection to their admission under that screen" |
| Release 选择问题消除 | **接受**；"the earlier 25% versus 2.6% exclusion contrast must no longer be used as evidence against this admitted cohort" |
| EFC 撤回 + 显式约定 | **接受**；"correctly retracted" |
| 反转改以循环间隔为尺度 | **接受改法**，但**不接受我断言的"至多一个循环"上界**——"a short reversal window can contain several cycles" |
| 数值共线性异议 | **实质缓解**；"condition number of 2.65, low VIFs ... support a well-conditioned three-column interval design" |

### 未被接受的（我的错误，必须记录）

1. **"至多一个循环的 Ah 跨 RPT 边界"上界不成立**——短反转窗内可能含多个循环。**撤回。**
2. **"预测问题已被不可约离散度回答"不成立**——失败的 conformal / 尺度收缩 / τ 选择
   只证明**那几种干预无效**，不构成贝叶斯误差下界。**已从结论删除 "irreducible"。**
3. **对比 (a) = 0 不是"所有分解都不可识别"的数学证明**——它只针对我采用的匹配规则与容差。
4. **`dSOH` 相关即使未拟合也属于结果检视**——必须披露，且不得据此挑选"看似无关"的主暴露。
5. **关闭的机制问题不得登记为"已被实验证伪的物理定律"**——只能登记为"识别未建立"。

### 保留的最强反对意见

> 关闭可能放弃一个工程预测增益；完整运行暴露历史或许确实在健康历史之外提供信息。
> 这个可能性**仍然开放**，本轮**未被否定**。不跑的理由是贡献门槛，不是"已知无效"。

### 重开条件（充要）

1. 受控或可辩护的运行对比，在可比应力下区分日历时长 / 循环数 / 电荷剂量，并有独立重复；
2. 具体且原创的测量或推断机制，对最接近文献成立，且带本数据**能区分**的可证伪预测；
3. 或把目标显式改为工程目标（改变目标，不回溯满足原创性）。

**不足以重开**：换特征编码、换回归器、换种子、换时钟轴，或在现有区间变量里找到显著关联。
