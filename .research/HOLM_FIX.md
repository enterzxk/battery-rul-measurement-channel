# Holm 实现缺陷与修正（2026-11-08）

## 缺陷（CD-013 指出）

我此前用的：

```python
adj[idx] = min(1.0, ps[idx] * (len(ps) - rank))
```

**缺累积最大值**，adjusted p 可能非单调，这违反 Holm 的定义。

## 正确实现

```python
order = np.argsort(p); adj_sorted = np.empty(n); running = 0.0
for i, idx in enumerate(order):
    running = max(running, p[idx] * (n - i))
    adj_sorted[i] = min(1.0, running)
```
