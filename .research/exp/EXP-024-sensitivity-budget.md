# EXP-024 · 后处理选择的敏感度预算

## 设计

固定一个头条对比（UConn，真实循环数，k=8，affine，m=1 vs m=2），**一次只改一个后处理决定**，看它把答案移动多少。

## 结果

| 变动的决定 | Δ | 相对基线的变化 |
|---|---:|---:|
| 基线（cell-macro, mean, per-cell, all, exact-k）| +18.34 | — |
| 聚合顺序 → query 池化 | +20.57 | +2.23（+12%）|
| 抽样聚合 → median | +17.26 | −1.07（−6%）|
| **仿射作用域 → 每工况共享** | **+68.65** | **+50.32（+274%）** |
| **评估总体 → 仅后期（RUL Q1）** | **−19.86** | **−38.19（−208%，符号翻转）** |
| 行分配 → floor(k/m) | +16.55 | −1.79（−10%）|

## 判定

**两个决定主导，三个次要，相差一个数量级。**

| 量级 | 决定 | 效应 |
|---|---|---|
| 主导 | 仿射作用域 | +274% |
| 主导 | 评估总体 | **符号翻转** |
| 次要 | 聚合顺序 | +12% |
| 次要 | 行分配 | −10% |
| 次要 | 抽样聚合 | −6% |

## 为什么这是可发表的测量学贡献

1. **它可量化**：不是「注意实现细节」这种空话，而是一张排序表。
2. **它可操作**：两个主导项都能在论文里写清楚（作用域怎么定、总体怎么划），三个次要项可以标准化掉。
3. **它解释了文献中的分歧**：如果不同论文对「供体数」给出不同结论，最可能的原因不是数据，而是这两个未声明的选择。
4. **它对本项目的结论有直接含义**：我们报的 +18.34 只在「per-cell + 全总体」这个格子里成立；换到「per-condition」是 +68.65，换到「仅后期」是 −19.86。

## 限制

- 只在 UConn 上做；ISU 未做同样的六格扫描
- 「仿射作用域」的 +274% 部分来自绝对误差水平变化（per-condition 让所有电芯共享一个拟合），不完全是「对比强度」的变化
- 「仅后期」那一格的 p=0.093，不显著，但符号翻转这件事本身是确定的
