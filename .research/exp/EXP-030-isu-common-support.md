# EXP-030 · ISU 扫描的共同支撑重跑

## 为什么做

诚信复检（FAIL-B）发现 `isu_budget.py:50-56` 用 `len(donors) < m` **逐臂**过滤被评估电芯，而 `summarize` 只对工况取交集。独立重算：

```
ISU 被评估电芯   m=1: 233   m=2: 223   差 10
受影响工况 4 个：19 / 21 / 53 / 63
```

即两臂的评估总体不同，不只是「改了一个决定」。

## 设计

采用主表（`isu_corrected.py:67-69`）的口径：合格电芯集合**一次固定**，按最大供体数判定；两臂共用。每臂 223 个电芯。每个配置用同一种子的新 RNG。

新增两个空操作对照：
- **N1**：baseline 用 seed=1 重跑（同一规格，不同随机流）
- **N2**：floor(k/m) 分配（K=8 下与 exact 行数相同，即同一实验换随机流）

## 结果

| 配置 | Δ | p | 改善 | 相对基线 |
|---|---:|---:|---:|---:|
| baseline | +0.132 | 0.0002 | 47/57 | — |
| 聚合顺序 → query 池化 | +0.126 | 0.0001 | 47/57 | −4% |
| 抽样聚合 → median | +0.082 | 0.0594 | 36/57 | −38% |
| **评估总体 → 仅后期** | **−0.155** | **0.0000** | 13/57 | **−218%（符号翻转）** |
| N1 同规格重跑（seed 1） | +0.156 | 0.0005 | 45/57 | +19% |
| N2 floor 分配（空操作） | +0.145 | 0.0001 | 47/57 | +11% |

## 与旧数字的对照

| 量 | 旧（不匹配支撑） | 新（共同支撑） |
|---|---:|---:|
| baseline | +0.089（p=0.125，不显著） | **+0.132（p=0.0002，显著）** |
| 聚合顺序 | −26% | **−4%** |
| 抽样聚合 | −43% | −38% |
| 评估总体 | −332% | **−218%** |
| 行分配（空操作） | +28% | +19% / +11%（两个实现） |

## 判定

1. **FAIL-B 已关闭。** 两臂现在都是 223 个电芯。
2. **基线变强而不是变弱**：共同支撑下 ISU 供体效应从 p=0.125 变为 **p=0.0002**。旧的不匹配支撑把基线压低了约 33%，并且让它看起来不显著。
3. **评估总体效应在两数据集上高度一致**：UConn **−208%**、ISU **−218%**，而两个空操作对照只有 10–19%。**这是全文唯一一个明确超出噪声的敏感度因子，而且它在两个数据集上几乎同值。**
4. **聚合顺序掉进噪声**：−4%，远小于 11–19% 的空操作范围。旧值 −26% 来自不匹配支撑。
5. **抽样聚合仍在边界**：−38%，约为空操作的两倍，且是唯一失去显著性的臂（p=0.0594）。可作为「中等」证据，不能当主导项。
