# Tier 2 结果（UConn，2026-11-07）

## 目的

检验方法层能否在通道层之上再推一档。预设判据：相对仅用放电曲线（A_curve）的增益 **≥12%** 才写进论文。

## 两个实现

### 2a 手工轨迹描述量（约定的基线方案）

每个 ECM 参数维取 4 个历史描述量（首值、当前值、斜率、极差），30 维 × 4 = 120 维，接同一个 HGB。

| 特征集 | LOGO 电芯宏平均 MAE |
|---|---:|
| A_curve | 6.587 |
| **A_curve + C_ecm** | **6.020** |
| A_curve + 轨迹描述量 | 6.805 |
| A_curve + C_ecm + 轨迹描述量 | 6.805 |
| 仅轨迹描述量 | 8.961 |

轨迹描述量**反而变差**（6.805 vs 6.020）。原因推断：当前时刻的 ECM 参数已经编码了历史，额外 120 维在 2,813 行上引入过拟合。

### 2b 序列编码器 + 测试时自监督适配（借 BatteryTTT）

GRU(20→32) 吃最近 16 次体检的 ECM 参数序列，拼接当前曲线特征；预训练用 RUL 回归 + 掩码重建双任务；测试时在目标工况的无标签序列上只用重建损失适配。

| 变体 | LOGO 电芯宏平均 MAE |
|---|---:|
| 无适配 | 7.520 |
| 全量转导适配 | 7.825 |
| 因果适配（只用目标电芯前半段） | 7.452 |

三个变体都劣于 HGB 的 6.020。逐组看极不稳定：第 6 组适配后从 6.654 降到 3.186，第 9 组从 11.79 升到 14.23。

## 结论

**方法层未通过预设判据。** 最好的结果仍是 Tier 1 的"HGB + 放电曲线 + ECM 参数"，LOGO 6.020，相对 A_curve 增益 8.6%，低于 12% 的门槛。

三条可复用的判断：

1. 64 电芯 / 2,813 行的规模撑不起神经网络，梯度提升树仍是上限。
2. 测试时自监督在目标工况上不稳定，逐组方向不一致，均值不改善。
3. 轨迹信息已被当前时刻的参数编码，显式加轨迹描述量是冗余。

## 对论文的影响

按事先约定的判据，方法叙事不成立，Introduction 应退回"通道"主线，Tier 2 作为负结果写入 Experiments 的稳健性分析。
