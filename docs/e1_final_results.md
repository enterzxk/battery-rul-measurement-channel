# E1/E2 最终结果（单脚本 / 单配置 / 4 seeds，2026-11-07）

> 本文件是 E1/E2 的**唯一权威数字**。此前 `tier1_results.md` 与 `tier2a_pass.py` 的输出因配置不同已作废，见各文件顶部标记。

## 配置

- 脚本：`scripts/e1_final.py`
- 模型：`HistGradientBoostingRegressor(max_iter=300, learning_rate=0.08)`，所有特征集共用
- 数据：UConn，2,813 行 / 64 电芯 / 11 工况组
- 标签：RUL = 到首次 SOH ≤ 80% 的剩余体检次数（0–77）
- 协议：LOGO（11 折）与 LOCO（64 折）
- 种子：{0,1,2,3}
- bootstrap：5000 次电芯级配对重采样

## 三条要点

1. **主结论不变**：8.6%（6.587 → 6.020），95% CI [−0.999, −0.133]，上界为 −0.133，比旧记录的 −0.025 更远离零。
2. **维度匹配后物理表示的优势缩小但仍在**：C_desc30（28 维，6.109）对比 C_ecm（30 维，6.020），差 0.089（1.5%）；而 C_desc20（20 维，6.155）时差 0.142（2.3%）。说明约三分之一到一半的"参数化优势"其实是维度效应。
3. **种子对结果无影响**：4 个种子的 LOGO 完全相同（std = 0），HGB 在此数据规模上是确定性的。真正的方差来自数据划分与电芯抽样，由 bootstrap 刻画。因此"多种子"不能替代 bootstrap，也不必再补种子。
