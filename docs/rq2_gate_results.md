# RQ2 闸门实验结果（UConn，2026-11-07）

## 设置

- 数据：UConn 慢脉冲 + 恒流放电，64 电芯 / 11 工况组
- 标签：首次 SOH ≤ 80% 时的循环数，RUL = EOL 循环 − 当前循环
- 样本：2,739 行（仅保留已退休电芯、退休前时刻），64 电芯
- 模型：HistGradientBoostingRegressor（max_iter=200, lr=0.1），**所有特征集共用同一模型**
- 指标：电芯宏平均 MAE（循环数）
- 协议：LOGO = 留一工况组（11 折）；LOCO = 留一电芯（64 折）
- gap = LOGO − LOCO，越小说明特征越不依赖工况

## 结果

| 特征集 | 维度 | LOGO | LOCO | gap |
|---|---:|---:|---:|---:|
| A_prefix（曲线 + 容量 + SOH） | 58 | 9.95 | 7.62 | 2.33 |
| **A_curve（仅放电曲线）** | 54 | 11.95 | 9.31 | 2.64 |
| **A_curve + C（曲线 + 脉冲）** | 74 | **10.32** | **8.28** | **2.04** |
| A_prefix + C | 78 | 10.13 | 7.93 | 2.20 |
| A_prefix + B + C | 84 | 10.03 | 7.87 | 2.16 |
| B_dcir（6 个 DCIR 标量） | 6 | 11.25 | 10.08 | 1.17 |
| C_pulse（仅脉冲描述量） | 20 | 11.37 | 9.80 | 1.58 |

## 三条结论

1. **脉冲特征对"只有放电曲线"的模型有实质增益**：LOGO 11.95 → 10.32（−13.6%），LOCO 9.31 → 8.28（−11.1%），且工况 gap 从 2.64 缩到 2.04。
2. **脉冲特征对"已有当前容量/SOH"的模型无增益**：9.95 → 10.13（略差）。
3. **脉冲特征是容量代理**：ΔV 与 SOH 的 Spearman |ρ| 最高 0.773（90% SOC 放电方向），全部 p ≈ 0。

## 单调性（补充）

脉冲描述量对体检序号 RPT 的 |ρ| 中位数：ΔV 0.79–0.90，弛豫残余比例 0.52–0.61，63% 恢复时间 0.23–0.39。
