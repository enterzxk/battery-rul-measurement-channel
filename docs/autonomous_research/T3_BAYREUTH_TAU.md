# T3：Bayreuth 侧 tau 触界率与时间尺度对比（2026-11-07）

## 目的

A6 的 B 节（可辨识性定律）前置条件：若 Bayreuth 的 tau1 也大面积触界，则 D-02 中 tau1 的"失败"不携带物理信息。

## 结果（20 个电芯 / 1,361 次拟合 / 0 失败）

| 项 | 值 |
|---|---|
| tau1 触下界（≤1.01e-4 h） | **0.0%** |
| tau1 触上界（≥0.495 h） | 0.0% |
| tau1 中位 | 0.0166 h = **59.8 s** |
| tau2 触下界 | 0.0% |
| tau2 触上界 | 0.1% |
| tau2 中位 | 0.364 h = **1310 s** |

## 与 UConn v2 的对比

| 量 | UConn（窗 60 s） | Bayreuth（窗 10800 s） |
|---|---|---|
| tau1 中位 | 2.13 s | 59.8 s |
| tau2 中位 | 21.1 s | 1310 s |
| tau1 / 窗宽 | 0.036 | 0.0055 |
| tau2 / 窗宽 | 0.35 | 0.12 |

## 两个结论

1. **Bayreuth 侧没有触界问题**，tau 是可辨识的。因此 D-02 的判负不受 UConn 拟合 bug 影响，仍然成立（与 A6 独立核查一致）。
2. **两个数据集的参数族时间尺度完全不重叠**：UConn 的 tau2（21 s）比 Bayreuth 的 tau1（60 s）还小。同名"2-RC 参数"在两个数据集上测量的是不同的物理过程（UConn：60 s 脉冲后的快弛豫；Bayreuth：3 h 静置的慢弛豫）。

**对 B 节的含义**：不能把两边的 tau 直接比较，只能用无量纲比 tau/W。而 tau/W 在两边落在不同区间（UConn 0.036–0.35，Bayreuth 0.0055–0.12），因此"同号率是 kappa 的函数"这条定律若成立，必须在合并前先做归一化，且需要说明这是两个不同物理过程的同一无量纲量。
