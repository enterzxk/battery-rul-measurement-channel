# B 节检验结果：可辨识性定律未获支持（2026-11-07）

## 预注册判据（A6 · D-14）

> 同号率随 kappa = tau/W 单调下降，且 Spearman rho 的 95% CI 不含零。

## 数据

- UConn：5,710 次修正后 2-RC 拟合，11 个工况，W = 60 s
- Bayreuth：1,649 次拟合，23 个工况，W = 10800 s
- 每个 (数据集, 参数) 得到一个点：kappa = median(tau)/W，signCons = 多数符号占比

## 结果

| 数据集 | 参数 | kappa | 同号率 | 工况数 |
|---|---|---:|---:|---:|
| Bayreuth | a1 | 0.00000 | 0.826 | 23 |
| Bayreuth | tau1 | 0.00000 | 0.696 | 23 |
| Bayreuth | a2 | 0.00003 | 0.609 | 23 |
| Bayreuth | tau2 | 0.00003 | 0.609 | 23 |
| UConn | a1 | 0.03442 | 0.636 | 11 |
| UConn | tau1 | 0.03442 | 0.545 | 11 |
| UConn | a2 | 0.34541 | **1.000** | 11 |
| UConn | tau2 | 0.34541 | **1.000** | 11 |
| UConn | c | 1.00000 | 1.000 | 11 |
| Bayreuth | c | 1.00000 | 0.652 | 23 |

**Spearman(kappa, signCons) = +0.375，p = 0.286，n = 10。**

## 判定

**假设失败。** 两个独立理由：

1. **方向相反**：预注册的是"单调下降"，实测是 +0.375（上升）。
2. **不显著**：p = 0.286，95% CI 必然包含零。

最致命的一行是 UConn 的 a2 / tau2：kappa = 0.345（最不可辨识的档位之一），同号率却是 **1.000**——与"越不可辨识越不稳定"完全相反。

## 对论文的影响（按预注册规则执行）

- B 节改写为「机制未获支持」，标题与摘要**不得出现"定律"字样**
- 论文退为纯 A：负结果 / 方法学
- 标题采用 A6 的备选方案：

> A Post-Mortem of a False Positive: How a Fitting Window and a Label Unit Manufactured an 8.6% RUL Gain

## 这一节仍然要写进论文的理由

否证本身是信息：**"参数不可辨识"并不能预测"参数跨工况不稳定"**。这直接否掉了本项目此前一个自然的猜测（慢扩散参数不稳定是因为拟合不好），也提醒后续工作不要用拟合质量去解释迁移性。

## 方法学注记

本检验只有 10 个点（kappa 实际只有 4 个不同取值），统计功效很低。因此结论应表述为「未观察到预注册的关系」，而不是「证明了不存在关系」。
