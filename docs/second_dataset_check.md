# 第二数据集核查：CALCE（2026-11-07）

## 发现

CALCE 数据门户 `https://calce.umd.edu/battery-data` 本机可达（200），共 89 个 zip。

| 系列 | 数量 | 内容 | 是否含 EIS |
|---|---:|---|---|
| CS2 | 15 | LCO 电芯全寿命循环（tab 分隔 txt，含 mV/mA/温度/容量） | ❌ 无 |
| CX2 | 12 | 同上 | ❌ 无 |
| A123 | 16 | 磷酸铁锂，DST/US06/FUDS 工况 | ❌ 无 |
| SP2 | 13 | 驱动循环 | ❌ 无 |
| **Impedance_25C / -5C / -40C / 50C** | 4 | **独立阻抗表征实验**（PL 软包电芯，`data/pln/`） | ✅ 有，但与老化轨迹不对齐 |

实测 `CS2_21.zip`：23 个 txt，列结构为 `Time / Status code / mV / mA / Temperature / Charge count / Discharge count / Capacity`，**没有任何阻抗或脉冲测量**。

## 结论

**CALCE 不能提供"随寿命演化的 EIS"**。它的 EIS 是独立表征实验，与 CS2 老化系列不是同一批电芯、也不是同一时间轴。

结合此前对 NASA 的核查（38 个文件中仅 4 个有完整寿命轨迹），可得一个明确判断：

> **在本机可达的公开数据集中，只有 UConn 一个同时具备「全寿命轨迹」与「非循环测量通道」。**
