## 承继的既有证据（来自 E:\桌面\rul 旧项目，作为新方向的约束条件）

新方向若落在同一批数据、同一套指标上，必须正面回答"与下列已否证结果的关系"，否则不可立项。

### 已否证（NO_GAIN）

| 类别 | 具体尝试 | 结果 |
|---|---|---|
| 表格/神经候选模块 | 41 个候选 | 0 通过双闸门（3 折 ≥2% 且 3/3；LOO ≥1% 且 CI 不含 0）|
| 序列/生成家族 | Mamba-SSM、条件流匹配、PatchTST+Prompt | 3 折偶有 +5.25%，LOO 全部归零或为负 |
| 表征层 | 协议无关特征编码器 | LOO 单种子 +2.70%，多种子 +1.46~1.66% |
| 自监督 | BMAE 式掩码预训练 | scratch 2.9630 / pretrained 2.7930，均劣于基线 2.6279 |
| 多任务 | 多阈值共享 HGB | C3 −6.3%，不如标签错配对照 |
| 个体适配 | 逐查询岭校正 | 逐电芯偏移不可辨识（R² ≤ 0.10）|

### 已成立（可作为新方向的已知事实）

1. **瓶颈在表征，不在模型**：逐循环"容量"通道是部分循环吞吐（0.133 vs 0.25 Ah），跨电芯不可比；喂给 ridge/HGB 得 4.25/5.07，而 HGB-F3 是 2.63。
2. **3 折收益系统性蒸发**：IDD +6.43% → LOO +0.89%；fullft +5.16% → −12.13%。
3. **全轨迹统计量归一化泄漏未来**：transductive EOL 投影 LOO 1.664（−18.6%），因果版退化到 2.713（−32.7%）。
4. **逐循环前缀特征是工况指纹**：组间量 r = 0.53~0.66，组内归一化衰减率 r = 0.02。
5. **另一条并行路线**：在参考电芯校准方向上取得过稳定增益，且"条件已在训练集内"时增益归零。该工作与本项目互不引用，具体数字不在此展开。
