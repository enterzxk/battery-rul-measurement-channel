# Tier-1 首轮结果（UConn，2026-11-07）

## 相对上一轮的三个修正

1. **时间轴改为 RPT 序号**。`num_cycles` 字段不可用：按 rpt 排序时 SOH 只有 16 处上升，按 num_cycles 排序有 **379 处**，说明该字段不按时间单调。RUL 因此以"剩余体检次数"为单位。负 RUL 归零（本轮 n_negative_rul = 0）。
2. **加入 2-RC 弛豫拟合**。对每条 101 点脉冲波形拟合 `v = c + a1·exp(-t/τ1) + a2·exp(-t/τ2)`，17,130 条全部收敛（NaN 率 0），耗时 49 s。
3. **补 5000 次电芯级配对 bootstrap**。

## 四条结论

1. **脉冲特征对循环曲线有增量，ECM 参数优于波形描述量**（6.053 vs 6.162 LOGO）。
2. **增益不是"跨工况专属"**：LOGO −7.3%、LOCO −10.3%，两个协议同时改善，gap 没有缩小（1.394 → 1.445）。所以它不是修工况，而是补信息。
3. **上一轮"脉冲是容量代理"的推断不成立**：本轮加上容量/SOH（A_prefix）反而比只有曲线差（6.716 vs 6.531）。脉冲提供的不是容量的替代品。
4. **脉冲单独用很弱**（7.786），它是补充通道，不是替代通道。

## 已知局限
